ボードとウェットが決まったら、残りの小物はそこまでお金はかかりませんが、これが欠けると快適に海に入っていられません。優先度の順に見ていきます。

## 一、日焼け止め：サーフィンで最も見落とされるダメージ

水面の反射で紫外線は倍増します。無防備に2時間サーフすれば、日焼け（やけど）は当たり前。

- **耐水・耐汗（Water Resistant）で高SPFのもの**を。SPF50+ がいちばん安心。
- **ミネラル系（酸化亜鉛 zinc）は耐水性が高く肌にやさしい**。難点は白くなること。日本のサーファーがよく使う**顔用の日焼け止め（サーフ用 / zinc スティック）**は、クレヨンのように頬や鼻に塗ると1セッション落ちない。
- **入水の20分前に塗る**こと。膜を作らせる。耳・首の後ろ・足の甲は塗り忘れやすい。
- **reef-safe（サンゴにやさしい）**処方を選ぶと海にもやさしい。

## 二、リーシュ（リーシュコード）

ボードを足首につなぐもの。転んでもボードが流れて人に当たらず、毎回泳いで取りに行く必要もない。**初心者必須の安全アイテム。**

- **長さ ≈ ボード長**：8フィートのボードなら8フィート前後のリーシュ。
- **太さ**：小波は細め（軽く抵抗が少ない）、大波は太め（丈夫）。初心者の小波は標準の太さでOK。
- **後ろ足**の足首に、コードが後ろ向きになるように。パドル中に絡まないように。

## 三、ワックス / デッキパッド

ボードの上で足が滑らないようにするもの。

<Figure
  src="/gear/wax-temp.jpg"
  alt="水温別のサーフワックス"
  caption="ワックスは水温別：寒いほど柔らかいものを（Cold → Cool → Warm → Tropical）。"
/>

- **ワックス**：水温に合わせて選ぶ——`Cold`（冷水）、`Cool`、`Warm`、`Tropical`（熱帯）。水温が低いほど柔らかいワックス。間違えると付かない・溶ける。ソフトボードは通常ワックス不要。
- **デッキパッド**：テール側に貼る。ショートに多く、ロング/ソフトは基本不要。
- 初心者はワックス1個を季節で選べば十分。

## 四、必要に応じた小物

| アイテム | いつ必要か |
|---|---|
| **フード / グローブ / ブーツ** | 真冬、水温15°C以下 |
| **耳栓（Surf Ears など）** | 頻繁に入る人、「サーファーズイヤー」（外耳道の骨増殖）予防 |
| **ノーズクリップ** | ローリングが多く、鼻に水が入りやすい人 |
| **ラッシュガード** | 真夏の日焼け・擦れ防止、ウェットの下にも |
| **お着替えポンチョ** | 駐車場での着替え、日本の海辺で定番 |
| **防水ケース / キーボックス** | 車の鍵・スマホ用、砂浜に置き忘れ防止 |

## 五、初心者の最小セット

必要最低限をそろえるなら、1セットは：

1. **ボード**（ソフトかファン）→ [初心者サーフボード一覧](/ja/gear/beginner-boards)
2. **ウェットスーツ**（3/2mm フルから）→ [ウェットスーツの選び方](/ja/gear/wetsuit)
3. **リーシュ**（ボード長に合わせる）
4. **ワックス**（ソフトなら省略可）
5. **耐水・高SPFの日焼け止め＋顔用 zinc**

あとは季節と頻度に合わせて少しずつ。最初から派手な小物にお金をかけないこと——予算はフィットするボードとウェットに回すのが、快適さを決めます。
