板和防寒衣搞定后，剩下这些小件花不了多少钱，但缺了会直接影响你能不能舒服地泡在水里。按优先级来看。

## 一、防晒：冲浪最容易被忽略的伤

水面反光会让紫外线加倍，冲浪两小时不防晒，晒伤是常事。

- **选防水 / 防汗（Water Resistant）的高倍数防晒**，SPF50+ 最省心。
- **矿物型（氧化锌 zinc）更耐水、更温和**，缺点是偏白。日本冲浪者常用的**面部防晒膏（サーフ用 日焼け止め / zinc stick）**，像蜡笔一样涂脸颊鼻子，一整场不掉。
- **下水前 20 分钟涂**，让它成膜；耳朵、后颈、脚背最容易漏。
- 选 **reef-safe（对珊瑚友好）** 的配方，对海洋更好。

## 二、脚绳 Leash（脚绳 / リーシュ）

把板拴在脚踝上，摔下来板不会冲走砸到别人，也不用每次游回去捡板。**新手必备，安全件。**

- **长度 ≈ 板长**：8 尺板配 8 尺脚绳左右。
- **粗细**：小浪用细的（轻、阻力小），大浪用粗的（结实）。新手小浪用标准粗细即可。
- 绑在**后脚**脚踝，绳扣朝后，避免划水时缠脚。

## 三、板蜡 Wax / 防滑垫

让脚站在板上不打滑。

- **板蜡**：按水温选对应款——`Cold`（冷水）、`Cool`、`Warm`、`Tropical`（热带），水温越低用越软的蜡。涂错了要么不粘要么化掉。软板通常不用打蜡。
- **防滑垫（Deck Pad / デッキパッド）**：贴在板尾，多见于短板，长板/软板一般不需要。
- 新手一块蜡按季节选就够。

## 四、按需的其他小件

| 物件 | 什么时候需要 |
|---|---|
| **防寒帽 / 手套 / 袜子** | 深冬水温 15°C 以下 |
| **耳塞（Surf Ears / 耳栓）** | 常冲、防止「冲浪耳」（外耳道骨增生） |
| **鼻夹** | 翻滚多、容易呛水的人 |
| **防磨衣 ラッシュガード** | 盛夏防晒防蹭板红疹，也可垫在防寒衣里 |
| **换衣斗篷 / 浴巾裙（Poncho）** | 停车场换衣服，日本海边很常见 |
| **防水袋 / 钥匙盒** | 放车钥匙手机，别丢在沙滩 |

## 五、新手一套最小清单

如果只置办最必要的，一套是：

1. **板**（软板或蛋型）→ 见 [新手冲浪板一览](/zh/gear/beginner-boards)
2. **防寒衣**（3/2mm 连身起步）→ 见 [防寒衣怎么选](/zh/gear/wetsuit)
3. **脚绳**（配板长）
4. **板蜡**（软板可省）
5. **防水高倍防晒 + zinc 面部膏**

其余按季节和频率慢慢添。别一开始就把钱花在花哨配件上——把预算留给合身的板和防寒衣，那两样才决定你冲得爽不爽。
